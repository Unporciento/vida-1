# Vida 1%

> Crecimiento personal, un 1% a la vez.

## Módulos

- **Hábitos:** avances cotidianos pequeños y sostenibles.
- **Orbit:** perspectiva del progreso y equilibrio personal.
- **Playground:** exploración sin juicio ni presión.
- **Vault:** espacio personal para guardar lo importante.
- **Genesis:** origen, intención y evolución de cada proceso.

## Principios de producto

1. Acompañar, nunca presionar.
2. Celebrar el progreso pequeño y constante.
3. Mantener una experiencia cálida, clara y humana.
4. Integrar los módulos sin perder su personalidad.
